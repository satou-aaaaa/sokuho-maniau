# 速報まにあう？（sokuho-maniau）

震源の深さと、震源の真上から町までの距離を見て、緊急地震速報と強いゆれ（S波）のどちらが先に届くか、余裕は何秒か（または間に合わないか）を当てる1日5問の学習ゲーム。正解したら、その深さで速報が間に合わない「壁」がどこかも選ぶ。浅い地震では、震源の真上から約20kmより近い町に速報は間に合わない（20キロの壁）。

遊ぶ: <https://satou-aaaaa.github.io/sokuho-maniau/>

- P波・S波の速さと、速報の解析や伝達にかかる時間は、気象庁「緊急地震速報の仕組み」<https://www.jma.go.jp/jma/kishou/know/jishin/eew/shikumi/shikumi.html> と「緊急地震速報の特性や限界」<https://www.jma.go.jp/jma/kishou/know/jishin/eew/shikumi/tokusei.html> によります。
- 秒の計算は目安です（余裕 ＝ √(距離²＋深さ²)÷4 −（深さ÷7＋4））。本物の速報は、地震や観測点によってもっと時間がかかることがあります。問題の地震は練習のための例で、本物の地震の記録ではありません。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
